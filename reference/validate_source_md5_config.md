# Ensure that the source config contains a nonempty `source_md5`.

Ensure that the source config contains a nonempty `source_md5`.

## Usage

``` r
validate_source_md5_config(source_config)
```

## Arguments

- source_config:

  A source configuration list, including a `source_md5` value.

## Value

A boolean indicating whether the expected key is present.
